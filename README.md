# Loan-Eligibility-Checker-Python

# Project Overview 

The Loan Eligibility Checker is a Python-based decision automation system designed to evaluate customer loan applications using predefined banking rules. The program determines whether a customer qualifies for a loan and categorizes the loan type based on financial and employment criteria.

This project focuses on core Python logic, simulating a real-world banking scenario where structured decision-making is critical.

# Objective

To automate the loan approval process by validating customer details and delivering a clear eligibility decision along with loan classification.

# Problem Description

Banks evaluate loan applications based on multiple customer parameters.
This program checks eligibility using:

* Age
* Monthly Income
* Credit Score
* Employment Status

The system ensures consistent, rule-based decisions without manual intervention.

# Eligibility Criteria
Parameter & Condition
* Age	≥ 21 years
* Monthly Income	≥ ₹20,000
* Credit Score	≥ 650
* Employment Status	Employed

# Loan Type Classification

* Premium Loan → Credit Score ≥ 750
* Standard Loan → Credit Score between 650 and 749

If any eligibility rule fails, the loan is rejected with a clear reason.

# Core Concepts Demonstrated

* Conditional Statements (if, elif, else)
* Logical Operators
* User Input Handling
* Business Rule Translation into Code
* Structured Decision Making

# Technology Stack

* Python 3
* Jupyter Notebook (for experimentation and validation)
