# loan-eligibility-checker-python

Project Overview
The Loan Eligibility Checker is a Python-based decision automation system designed to evaluate customer loan applications using predefined banking rules. The program determines whether a customer qualifies for a loan and categorizes the loan type based on financial and employment criteria.

This project focuses on core Python logic, simulating a real-world banking scenario where structured decision-making is critical.

Objective

To automate the loan approval process by validating customer details and delivering a clear eligibility decision along with loan classification.
